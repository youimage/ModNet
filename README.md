# ModNet（整数論ニューラルネット）紹介

## はじめに

ModNetは、従来の深層学習における微分可能性や連続空間の仮定を捨て、  
**整数環上で動作する新しいニューラルネットワークモデル**です。  
このモデルは、非連続かつ非微分可能な演算であるmod演算を活性化関数に用い、  
整数のみで計算を行うことで、計算コストの大幅削減とハードウェア実装の簡素化を実現します。

---

## 背景と課題

- 伝統的なニューラルネットワークは連続値（実数）と微分可能性に依存している  
- GPUや高性能計算資源が必要で、リソース制約のある環境での実装が困難  
- 浮動小数点演算に伴う誤差や不安定性の問題  
- 既存の軽量化手法は連続空間前提であり、根本的な計算負荷削減には限界がある

---

## ModNetの基本概念

- **計算の全てを整数環 \(\mathbb{Z}/N\mathbb{Z}\)（mod N）上で行う**  
- 入力・重み・バイアスは整数で表現され、演算はすべて剰余演算を伴う  
- 活性化関数はmod演算自体、もしくはmodに基づく整数関数で代替  
- 勾配計算を用いず、進化的アルゴリズムや全探索で学習を行う

---

## 数学的定式化

各ニューロンの出力は次式で計算される。

\[
y = \left( \sum_{i=1}^n w_i x_i + b \right) \mod N
\]

- \(x_i\)：入力（整数）  
- \(w_i\)：重み（整数）  
- \(b\)：バイアス（整数）  
- \(N\)：モジュロ値（素数や合成数を選択）

mod演算により、出力は常に \([0, N-1]\) の整数となる。

---

## ネットワーク構造

- 層構造は従来のニューラルネットと同様に多層化可能  
- 各層の計算は上記のmod演算を基本とする線形結合で構成  
- 活性化関数はmodの性質に由来する非線形性を活用  
- 入力データは適切に整数化（量子化）して与える

---

## 学習アルゴリズム

- 微分可能性がないため、勾配降下法は使えない  
- 遺伝的アルゴリズム（GA）や全探索、進化的戦略などの非勾配法を用いる  
- 適応度関数として予測精度を評価し、重み・バイアスの組み合わせを最適化  
- 小規模問題では全探索も実用的

---

## 利点と応用可能性

- **計算リソースの大幅削減**：整数演算のみでGPU不要  
- **エッジAIへの適合**：マイコンやFPGAに直接実装可能  
- **安定性の向上**：浮動小数点誤差の影響を受けない  
- **暗号理論や符号理論との親和性**：整数環上の演算を活用した応用が期待できる

---

## 参考実装例（Python）

```python
def modnet_neuron(inputs, weights, bias, modulus=7):
    dot = sum(i*w for i, w in zip(inputs, weights))
    return (dot + bias) % modulus

def modnet_forward(x, layers, modulus=7):
    for layer in layers:
        x = [modnet_neuron(x, w, b, modulus) for (w, b) in layer]
    return x
